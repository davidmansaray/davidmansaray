# David Mansaray

Hi! 👋 I'm a product engineer. I like understanding what's getting in the way and finding elegant solutions.

Often that means building something small enough to learn from, then following the questions it raises.

What will have the most impact on the business? How should it feel to use? What happens behind the scenes when something fails, or the team needs to change it? Bringing those pieces together through design and engineering, in a way that benefits everyone involved, is what I really enjoy.

## Selected work

### [Switchboard](https://github.com/davidmansaray/switchboard)

A control room for people and agents managing hire bookings, built with Next.js, TypeScript and Mastra. A booking can change while an agent is working on it. Switchboard keeps drafts, evidence and approvals tied to the current booking, and makes recovery something you can follow.

[Try the demo](https://switchboard.davidmansaray.com)

### [Fellwise](https://github.com/davidmansaray/fellwise)

An outdoor-experiences marketplace demo built with Laravel and Filament. An editor changes a listing and presses Save. When does the booking system see it? Fellwise makes delivery, failures and recovery visible, with the controls to investigate and put things right.

[Try the demo](https://fellwise.davidmansaray.com)

### [Semblaro](https://app.semblaro.com/)

A 3D shelf-design tool. Turn a photo into an adjustable 3D model and a draft cut list for a maker.

### [Yondilo](https://world.yondilo.com/)

An explorable 3D world built from real map data.

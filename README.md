# David Mansaray

I build products, from understanding the problem and designing the interface to writing and running the software.

I like getting close enough to the work to see where it gets awkward. What does someone need to know? What decision are they trying to make? What is the smallest useful thing we can put in their hands and learn from?

These projects show how that thinking reaches the interface and the systems underneath it.

## Selected work

### [Fellwise](https://github.com/davidmansaray/fellwise)

An editor changes a listing and presses Save. When does the booking system see it? A fictional outdoor-experiences marketplace that makes delivery, failures and recovery visible, with the controls to investigate and put things right.

[Try the demo](https://fellwise.davidmansaray.com)

### [Outboss](https://github.com/davidmansaray/outboss)

Who is this person, what have we already said, and what should happen next? An outreach workspace that keeps people, campaigns and replies connected, with an explicit review before sending.

The repository includes a runnable local demo with synthetic records, fake mail providers and sending disabled.

### [Switchboard](https://github.com/davidmansaray/switchboard)

A booking changes while an agent is working on it. A hire-desk control room that keeps drafts, evidence and approvals tied to the current booking, and makes recovery something you can follow.

[Try the demo](https://switchboard.davidmansaray.com) — fictional data, a scripted model by default and simulated email.

## How I work

Product decisions, interface design and engineering inform each other. I work across Laravel, PHP, Vue, Next.js and TypeScript, with APIs, queues and agent workflows where the problem calls for them. Each repository explains what you can try, how it works and where the demo stops.
